Tools

Modal generator

Shape the partials of a Zebra 3 modal profile, hear a preview, and download the file Zebra reads.

Moving these controls rebuilds all 64 partials. Edits in the list stay until the next rebuild.

The preview approximates Zebra 3's modal resonator and is not verified against it. Strike position uses a string-like mode shape, which is only an approximation. Hold a key for the bow.

Drag a partial up or down for gain. Shift-drag it sideways for ratio. Draw paints a gain curve. Undo and redo cover those edits.

#RatioGain dBDecay

From a recording

Drop a wav, mp3, or aiff. It is decoded in this browser and is not uploaded. Noisy takes can be thinned with the threshold.

Root appears after analysis.

Click a partial number to make it ratio 1. Type a note or a frequency to override the root.

Describe

Optional. Sends one sentence to a small model, which sets the controls above. The editor works without it.
