Library

Tonverk presets

Multisample instruments for the Elektron Tonverk. Each one opens on Gumroad.

Bass

  • Chip Pulse Bass

    Standard chiptuney bass made with pulse waves

  • Sine Bass Stab

    Short stab, great for bass stab duties.

Pianos & Keyboards

  • Pulse Pluck Delay at 120 BPM

    Modulated pulse width pluck with a pseudo delay tail. No Delay FX were used, but the 'delay' effect achieved in the oscillator was set to 120 bpm.

  • Studio Grand Piano

    3 microphone studio grand.Recorded with 3 note intervals & 3 velocity layers.

  • Vintage Upright Piano

    3 microphone vintage upright. Recorded with 3 note intervals & 3 velocity layers.

Mallets

  • Glocken 1

    Synthesized Glockenspiel with a closed filter for a muted, darker sound.

  • Glocken 2

    Synthesized Glockenspiel

  • Glocken Inharmonic

    Synthesized Glockenspiel with inharmonic overtones.

  • Glocken Metallic

    Synthesized metallic sounding Glockenspiel.

Percussion

  • Orchestral Percussion VSCO

    Autosampled version of the 'GM Style Perc' VSCO sample pack. Trimmed so that the samples span the entire +3 and -3 of the Tonverk keyboard.
